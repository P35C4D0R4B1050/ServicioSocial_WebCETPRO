# Entregables

Documentos formales del proyecto. Los dos primeros son **línea base**: se aprobaron en su versión y no se editan (solo se actualizan sus enlaces cuando cambia la estructura de carpetas). A partir de ahora, un cambio de comportamiento se hace en [`docs/`](../docs/README.md) y se anota en el control de cambios del documento que lo contiene.

| Archivo | Qué es | Estado |
| :--- | :--- | :--- |
| [`Documento-de-Analisis-ERS-v1.1.md`](Documento-de-Analisis-ERS-v1.1.md) | Documento de Análisis de Requerimientos (ERS) v1.1: requisitos con identificadores estables, límites del sistema y mapeo a specs. | Línea base aprobada |
| [`Documento-de-Arquitectura-v0.4.md`](Documento-de-Arquitectura-v0.4.md) | Documento de Arquitectura v0.4: decisiones AD-01 a AD-36, despliegue, seguridad y SDD. | Línea base aprobada |
| [`Propuesta-Sistema-de-Matricula-CETPRO.docx`](Propuesta-Sistema-de-Matricula-CETPRO.docx) | Propuesta de arquitectura en Word, con el formato de `Contexto/Referencia-de-formato/Propuesta_Librería.pdf`. | Borrador para revisión: la portada usa la tutora y los integrantes del Informe 004 (nombres tal como allí figuran) y la Facultad y Escuela del PDF de referencia |

La propuesta resume los dos documentos y la documentación viva a la fecha de su redacción (21-oct-2026). Si `docs/` cambia en algo que ella afirma, se regenera o se corrige en Word.
